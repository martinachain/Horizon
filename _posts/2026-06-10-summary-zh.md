## [npm v12 重大变更：默认禁用脚本等](https://github.blog/changelog/2026-06-09-upcoming-breaking-changes-for-npm-v12/) ⭐️ 8.0/10

npm v12 将引入重大变更，包括默认关闭 allowScripts、通过 --allow-git 限制 Git 依赖，以及将 node_modules 设为只读。这些变更旨在提高安全性并与现代包管理实践保持一致。 这些变更影响所有使用 npm 的 JavaScript 开发者，可能破坏依赖安装脚本或 Git 依赖的工作流程。向更严格默认值的转变反映了缓解供应链攻击的行业趋势。 allowScripts 默认关闭的变更紧随 pnpm 的步伐，后者在 18 个月前实现了类似功能。--allow-git 变更关闭了一个代码执行路径，即 Git 依赖的 .npmrc 可能覆盖 Git 可执行文件。

hackernews · plasma · Jun 9, 21:01 · [社区讨论](https://news.ycombinator.com/item?id=48467705)

**背景**: npm 是 Node.js 的默认包管理器，用于安装和管理依赖。安装脚本（如 postinstall）一直是安全问题，因为它们可以在安装过程中执行任意代码。Vendored node_modules 指的是将依赖本地存储在项目中的做法。

## [在 FPGA 上通过 KAN 实现超快机器学习](https://aarushgupta.io/posts/kan-fpga/) ⭐️ 8.0/10

Aarush Gupta 展示了在 FPGA 上实现 Kolmogorov-Arnold 网络（KAN），以实现亚微秒级的机器学习推理，重点在于降低延迟而非提高吞吐量。 KAN 与 FPGA 的结合可能为边缘计算应用（如实时控制和高频交易）带来超低延迟的机器学习推理，每一微秒都至关重要。 该实现使用小型 KAN 模型（例如 2-5-1 架构），在 Xilinx FPGA 上实现了低于 1 微秒的推理时间，但扩展到更大模型受限于 FPGA 资源。

hackernews · ag2718 · Jun 9, 19:21 · [社区讨论](https://news.ycombinator.com/item?id=48466277)

**背景**: Kolmogorov-Arnold 网络（KAN）是一种神经网络架构，用可学习的单变量函数替代线性权重，灵感来自 Kolmogorov-Arnold 表示定理。FPGA（现场可编程门阵列）是可重构硬件，可针对低延迟推理进行优化。传统上，FPGA 上的机器学习推理通常优先考虑吞吐量，而这项工作专注于最小化非常小模型的延迟。
