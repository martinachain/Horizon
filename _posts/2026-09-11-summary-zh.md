## [OpenAI 发布托管式 Agents API，用于生产级 AI 智能体](https://developers.openai.com/api/docs/guides/agents-api/overview) ⭐️ 8.0/10

OpenAI 发布了 Agents API，这是一项托管服务，开发者只需一次 API 调用，指定任务、模型、工具和环境，即可创建生产级智能体，底层运行框架由 OpenAI 托管和维护。该 API 围绕四个核心概念构建——Agent（智能体）、Environment（环境）、Session（会话）和 Events/items（事件与条目），并支持自动上下文压缩、多智能体编排、程序化工具调用以及 MCP。 这标志着 OpenAI 正试图掌控智能体基础设施层，而不仅仅是模型本身，这可能会为那些不想自行构建和运维运行框架的开发者简化智能体部署。同时，这也加剧了关于智能体抽象层和供应商锁定的争论，因为 LangGraph、CrewAI 和 Microsoft Agent Framework 等竞品提供了不同的编排方案。 该 API 运行 Codex 运行框架，并支持可选的自托管沙箱，这可以简化供应商之间的迁移并缓解锁定担忧。然而，一些开发者质疑，在如今托管 Python 服务已很容易的情况下，托管服务是否必要；另一些人则指出，当主要痛点在于如何让智能体访问本地数据时，这种抽象可能并不适用。

hackernews · aquir · Sep 10, 19:43 · [社区讨论](https://news.ycombinator.com/item?id=49649213)

**背景**: AI 智能体是利用大语言模型自主执行多步骤任务、调用工具并与环境交互的系统。构建智能体需要一个“运行框架”（harness）——即管理状态、工具调用和上下文的编排层——而这一层的构建和运维非常复杂。OpenAI 的 Agents API 将这一运行框架作为托管服务提供，类似于云平台对服务器的抽象，但也引发了关于控制权、可移植性和锁定的问题。

## [印度以数字卢比结算启动 6200 亿美元公司债市场代币化](https://www.coindesk.com/markets/2026/09/11/india-starts-tokenizing-usd620-billion-corporate-bond-market-with-digital-rupee-settlement) ⭐️ 8.0/10

印度已开始对其规模达 6200 亿美元的公司债券市场进行代币化，并通过其中央银行数字货币（CBDC）——数字卢比进行结算。这是区块链代币化在主要固定收益市场中规模最大的国家级部署之一。 这标志着区块链和 CBDC 技术在国家层面的大规模实际应用，可能影响其他国家设计其金融市场基础设施的方式。如果成功，它有望缩短结算时间、降低交易对手风险，并成为全球其他资产类别代币化的范本。 该计划使用数字卢比进行代币化公司债券的结算，印度储备银行（RBI）自 2022 年以来一直在试点数字卢比。代币化支持部分所有权和原子结算，即付款与交割同时发生、无需中介，不过代币化证券的监管与合规框架仍在演进中。

rss · CoinDesk · Sep 11, 05:13

**背景**: 中央银行数字货币（CBDC）是由中央银行发行和管理的法定货币数字形式，此处指印度储备银行的数字卢比，可与实体货币按面值兑换。代币化是指将公司债券等现实世界资产以区块链上的数字代币形式表示，可提升透明度、支持部分所有权并简化结算。基于区块链的结算引入确定性或“原子”结算，即付款与收款同时发生、无需中介，相比传统交易后流程可降低交易对手风险和核对成本。

## [Citadel Securities 呼吁 SEC 对与股票挂钩的事件合约行使监管权](https://www.theblock.co/news/regulation/2026-09-10-citadel-urges-sec-assert-oversight-event-contracts-tied-public-firms-414140) ⭐️ 6.0/10

Citadel Securities 致函美国证券交易委员会（SEC）和商品期货交易委员会（CFTC），敦促两家机构确认与美股上市公司挂钩的事件合约应由 SEC 监管，此举直接挑战了 CFTC 对这类产品的自我认证流程。该公司主张，与股票挂钩的事件合约和永续衍生品应继续处于 SEC 的监管之下，而不应仅通过 CFTC 的自我认证程序上市。 这一干预可能重塑美国对与股票挂钩的预测市场和事件合约的监管方式，并可能引发 SEC 与 CFTC 之间的管辖权之争。对于上市或计划上市此类产品的交易所、经纪商和金融科技平台而言，这一事件至关重要，因为结果可能决定它们是否会面临更严格的证券式监管。 争议的核心在于 CFTC 的自我认证流程，该流程允许交易所在仅提前一个工作日通知的情况下上市新的事件合约，除非 CFTC 提出异议。Citadel 的信函特别针对与股票挂钩的事件合约和永续衍生品，认为涉及上市公司的产品属于 SEC 传统证券监管的范畴。

rss · The Block · Sep 10, 13:43

**背景**: 事件合约是一种二元化的“是/否”衍生品，根据特定事件是否发生来结算，在美国受监管市场中已存在二十多年。预测市场会上市这类合约，而交易所通常利用 CFTC 的自我认证流程快速推出产品。SEC 与 CFTC 的管辖权虽有重叠但各有侧重，SEC 监管证券，CFTC 监管商品和期货，这使得与上市公司股票挂钩的产品面临监管归属的模糊地带。
