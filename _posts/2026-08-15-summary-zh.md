## [Firefox 成为最后一个支持 uBlock Origin 的主流浏览器](https://www.pcworld.com/article/3212428/firefox-is-now-the-last-major-browser-that-still-supports-ublock-origin.html) ⭐️ 8.0/10

Firefox 现在是唯一仍支持 uBlock Origin 的主流浏览器，因为谷歌 Chrome 和其他基于 Chromium 的浏览器已过渡到 Manifest V3，这限制了广告拦截功能。这一变化凸显了 Firefox 在维护用户选择和隐私方面的独特地位。 这很重要，因为 uBlock Origin 是一个广泛使用的广告拦截器，在其他浏览器上失去它可能会减少用户对在线跟踪和侵入性广告的控制。Firefox 的持续支持为重视隐私的用户提供了替代选择，可能影响浏览器市场份额，并推动更用户友好的扩展政策。 Manifest V3 移除了大多数扩展的 webRequestBlocking 权限，将广告拦截器限制为功能较弱的 declarativeNetRequest API。Firefox 继续支持 Manifest V2，使 uBlock Origin 能够完整运行，而 Chromium 浏览器存在非官方移植版（uBlock-mv3），但面临限制。

hackernews · DemiGuru · Aug 14, 19:03 · [社区讨论](https://news.ycombinator.com/item?id=49303202)

**背景**: Manifest V3 是谷歌为 Chrome 引入的新扩展规范，旨在提高安全性、隐私和性能，但限制了广告拦截器使用的某些 API。uBlock Origin 依赖 webRequest API 来阻止网络请求，而该 API 在 MV3 中已对大多数扩展弃用。这一变化一直存在争议，批评者认为它降低了广告拦截器的有效性，并可能有利于谷歌的广告收入。
