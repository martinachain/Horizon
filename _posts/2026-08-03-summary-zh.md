## [Kakehashi：在 Linux ARM 上运行 macOS 二进制文件](https://github.com/wie-project/kakehashi) ⭐️ 8.0/10

Kakehashi，一个实验性的用户空间翻译层，现已成功在 Linux ARM64 上运行 macOS 命令行二进制文件，并提供了 7-Zip、curl 和 Xcode Git 工具的工作原型。它无需 JIT 即可翻译 Darwin Mach-O 二进制文件和 BSD 系统调用。 该项目解决了重大的技术挑战，有望使 macOS 软件在 Linux ARM 硬件上运行，类似于 Wine/Proton 对 Windows 应用的支持。它可能扩展 Linux 生态系统，并在 ARM 平台上提供 Darling 的替代方案。 Kakehashi 以 CLI 为先，不使用 JIT；它映射独立的 libSystem 并翻译 BSD 系统调用。目前性能显示 7-Zip 运行速度比原生 Linux 慢约 5.2 倍，但已有优化计划。

hackernews · vlad_kalinkin · Aug 2, 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49145937)

**背景**: macOS 二进制文件使用 Mach-O 格式，并依赖 macOS 系统库（如 libSystem）和 BSD 系统调用。在 Linux 上运行它们需要翻译这些组件。Darling 是一个类似的项目，旨在 Linux 上提供 macOS 兼容层，但其 ARM64 支持仍在进行中。
