The proposal faces an early August activation deadline with miner support below 1%. This proposal reignites a fundamental governance debate about Bitcoin's purpose—whether it should remain strictly peer-to-peer electronic cash or accommodate non-financial applications like NFTs and data storage. The outcome could set a precedent for how Bitcoin handles future protocol changes and community conflicts. BIP-110 would restore a smaller limit for OP_RETURN outputs, which are commonly used to attach data to Bitcoin transactions, and restrict larger data uploads. The proposal is a consensus soft fork, meaning it requires strong miner support to activate, but current support is near zero.

rss · Decrypt · Jul 15, 19:43

**Background**: Bitcoin's blockchain was originally designed for financial transactions, but users have increasingly used it to store non-financial data like images and text via OP_RETURN outputs. This has led to debates similar to the Blocksize Wars, where the community was divided over whether to increase block size limits. BIP-110 aims to curb this trend by temporarily limiting arbitrary data, arguing it preserves Bitcoin's core purpose as sound money.

## [SQLite Should Adopt Rust-Style Editions](https://mort.coffee/home/sqlite-editions/) ⭐️ 7.0/10

A proposal suggests that SQLite adopt Rust-style editions, allowing users to opt into breaking changes and improved defaults via a PRAGMA statement like 'edition = 2026', while maintaining backward compatibility for existing databases. This proposal addresses long-standing issues with SQLite's default behaviors that can lead to subtle bugs, offering a concrete path to modernize the database without breaking existing applications, which could benefit millions of developers. The editions would be stored in the database file header, enabling tools to detect the edition and apply appropriate defaults. However, moving database files between machines with different SQLite versions could cause compatibility issues if the reader doesn't support the edition.

hackernews · gnyeki · Jul 15, 22:42 · [Discussion](https://news.ycombinator.com/item?id=48928135)

**Background**: SQLite is a widely used embedded database known for its strong backward compatibility guarantee: newer versions can always read files created by older versions. Rust editions are a mechanism that allows the language to introduce breaking changes in a controlled way, where each crate declares which edition it uses, and the compiler handles migration largely automatically.
