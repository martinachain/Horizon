## [在 32GB 内存笔记本上运行 GLM 5.2 的 Colibrì项目](https://github.com/JustVugg/colibri) ⭐️ 7.0/10

一位开发者创建了 Colibrì，这是一个基于 C 语言的最小化推理引擎，通过 int4 量化和按需从磁盘流式加载专家模块，在 32GB 内存笔记本上运行了 744B 参数的 GLM 5.2 模型。 这表明即使超大规模的混合专家模型也能在没有 GPU 的消费级硬件上运行，让更多人能够本地运行最先进的 LLM。 该引擎是一个约 1300 行的 C 语言文件，无 BLAS 或 Python 运行时，通过将密集部分（约 9.9 GB）保留在 RAM 中，并从磁盘流式加载路由专家（约 370 GB）并配合 LRU 缓存，冷启动时达到约 0.1 tok/s。

hackernews · vforno · Jul 9, 08:05 · [社区讨论](https://news.ycombinator.com/item?id=48842459)

**背景**: GLM 5.2 是 Z.AI 开发的 744B 参数混合专家模型，每个 token 激活 40B 参数。Int4 量化通过将权重存储为 4 位整数来减少内存占用。多 token 预测（MTP）是一种同时预测多个未来 token 以加速推理的技术。
