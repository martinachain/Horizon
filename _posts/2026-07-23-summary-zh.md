## [GigaToken：通过 SIMD 实现约 1000 倍更快的 LLM 分词](https://github.com/marcelroed/gigatoken/) ⭐️ 8.0/10

GigaToken 是一个开源库，通过使用 SIMD 优化的预分词和缓存策略，实现了约 1000 倍更快的语言模型分词速度。 这一突破显著降低了训练大型语言模型时离线数据预处理的时间和成本，在准备数 TB 文本语料时能够实现更快的迭代周期。 加速来自于用 SIMD 优化的实现（支持 AVX512、AVX2 和 NEON）替代基于正则表达式的预分词，并结合激进的预分词映射缓存以减少分支。

hackernews · syrusakbary · Jul 22, 17:20 · [社区讨论](https://news.ycombinator.com/item?id=49010167)

**背景**: 分词是将原始文本转换为语言模型可以处理的 token 序列的过程。预分词通常使用正则表达式完成，是这一流程中的主要瓶颈。SIMD（单指令多数据流）允许并行处理多个字符，从而大幅加速文本操作。

Bento 是一个自包含的单个 HTML 文件（约 560KB），提供完整的幻灯片工具，包括编辑、查看、动画和实时协作，完全离线运行，无需外部依赖或云登录。 这代表了一种新颖的演示软件方法，消除了安装、云账户和网络需求，使得幻灯片只需浏览器即可随处携带和编辑。它也符合日益增长的本地优先软件运动，可能激发更多自包含的 Web 应用。 该文件将幻灯片数据以纯 JSON 块存储在顶部，应用逻辑则作为 base64 blob 嵌入，通过 DecompressionStream 在浏览器中解压。协作使用加密的盲中继（blind relay），中继服务器永远看不到数据，整个项目在 GitHub 上以 MIT 许可证发布。

## [每个人都应该了解 SIMD](https://mitchellh.com/writing/everyone-should-know-simd) ⭐️ 8.0/10

Mitchell Hashimoto 发布了一篇全面指南，主张 SIMD（单指令多数据）是每个开发者都应了解的关键优化技术，并提供了实际示例和性能见解。 这篇文章将 SIMD 从一个小众的低级话题提升为广泛相关的技能，帮助开发者编写更快的代码，并更好地理解编译器行为和硬件能力。 该指南涵盖了手动 SIMD 内联函数和编译器自动向量化，强调即使开发者自己不编写 SIMD 代码，了解其原理也有助于设计对 SIMD 友好的算法。

hackernews · WadeGrimridge · Jul 22, 17:48 · [社区讨论](https://news.ycombinator.com/item?id=49010648)

**背景**: SIMD 允许一条 CPU 指令同时对多个数据元素执行相同操作，显著加速图像处理、矩阵运算和音频编码等任务。现代编译器可以自动向量化循环，但常因数据依赖或复杂控制流而失败。了解 SIMD 有助于开发者编写编译器能有效优化的代码。
