## [Rust Portable SIMD Runs on GPUs via VectorWare](https://www.vectorware.com/blog/simd-on-gpu/) ⭐️ 7.0/10

VectorWare has announced that Rust's portable SIMD library (core::simd) can now compile and run on GPUs, mapping SIMD vectors directly to GPU warps without requiring intrinsics or code rewrites. This allows the same Rust SIMD code to target both CPU and GPU. This development simplifies GPU programming in Rust by reusing familiar SIMD abstractions, potentially lowering the barrier for high-performance computing. It could lead to more portable and maintainable code across CPU and GPU architectures, impacting fields like scientific computing and graphics. The implementation maps each std::thread to a GPU warp and uses the parallel lanes within the warp for SIMD operations. However, portable SIMD is currently only available on nightly Rust, and the fixed-width SIMD vectors may not achieve optimal performance without static GPU information.

hackernews · sagacity · Aug 10, 18:12 · [Discussion](https://news.ycombinator.com/item?id=49247477)

**Background**: SIMD (Single Instruction, Multiple Data) allows a processor to perform the same operation on multiple data points simultaneously. Rust's portable SIMD library provides a target-independent abstraction for SIMD operations, unlike target-specific intrinsics. VectorWare is a project that brings Rust threads to GPUs, and this new capability extends that to SIMD operations.
