## [DuckDB Labs 推出 DuckLake：以 SQL 数据库为元数据目录的数据湖格式](https://github.com/duckdb/ducklake) ⭐️ 8.0/10

DuckDB Labs 推出了 DuckLake，这是一种开放的数据湖（lakehouse）格式，将全部表元数据存储在支持 ACID 的 SQL 数据库中，而实际数据仍以 Parquet 文件形式存放在对象存储上。它旨在与 DuckDB 及其他查询引擎配合使用，并已催生出 Rust/DataFusion 移植版和 Quack 协议等生态项目。 DuckLake 通过用 SQL 目录取代基于文件的元数据清单，为 Apache Iceberg 和 Delta Lake 提供了一种更简单的替代方案，有望降低 lakehouse 部署的运维复杂度。它的出现表明 DuckDB 生态正从嵌入式分析数据库扩展为更广泛的数据平台，将影响正在评估开放表格式的数据工程师和分析团队。 DuckLake 目前仍处于 alpha 质量阶段：社区反馈指出在 v1.5.4 上按目录过滤的计数功能存在缺陷，且 DuckDB v2 的 SQL 解析器大约慢了 10 倍。其访问控制仅限于底层对象存储桶所支持的能力，因此没有列级或行级安全控制，也不支持列掩码。

hackernews · saikatsg · Oct 7, 17:40 · [社区讨论](https://news.ycombinator.com/item?id=49996149)

**背景**: DuckDB 是一个开源、面向列的嵌入式关系数据库，专为 OLAP（分析型）工作负载设计，理念上类似 SQLite，但针对大规模分析而非事务处理进行了优化。Lakehouse 将数据湖的低成本存储与数据仓库的表语义和可靠性结合起来，而现有的 Apache Iceberg 和 Delta Lake 等格式通常将元数据以文件（清单）形式存放在对象存储中。DuckLake 的关键设计选择是改为将元数据保存在 SQL 数据库中，从而提供 ACID 保证和熟悉的查询接口。

## [Cactus Compute 发布 16.9 MB 端侧语音转文字模型 Whistle](https://cactuscompute.com/blog/whistle) ⭐️ 7.0/10

Cactus Compute 发布了 Whistle，一个体积仅 16.9 MB、可在 CPU 上本地运行的紧凑型语音转文字模型。它支持英语、德语、法语、西班牙语、意大利语、荷兰语和波兰语，能一次性转写最长 30 秒的 16 kHz 单声道录音，并返回词级时间戳和概率。 Whistle 表明实用的语音识别如今可以塞进极小的端侧体积中，这对注重隐私、离线运行以及不希望把音频上传到云端的嵌入式应用非常重要。它也降低了业余爱好者和边缘开发者使用语音输入的门槛，无需 GPU 或庞大的模型下载。 该模型经过量化感知训练，以单个端侧文件形式发布，并与 Cactus 的 14 MB Needle 工具调用模型共用容器和引擎，因此一次构建就能让 Needle 获得音频输入能力。社区测试表明，在自由形式转写中其准确率远低于 Qwen ASR 等更大模型，而且录音过程中不支持流式输出。

hackernews · gmays · Oct 8, 16:59 · [社区讨论](https://news.ycombinator.com/item?id=50008427)

**背景**: 语音转文字（ASR）模型传统上体积庞大且计算密集，通常需要云服务器或强大的 GPU。近年来模型压缩、量化和边缘优先架构的研究，推动 ASR 走向可在 CPU 或 NPU 上运行的小型本地模型。Whistle 正是这一趋势的一部分，用一定的准确率换取小到几乎可以嵌入任何设备的体积。

欧盟执法机构欧洲刑警组织（Europol）周三发布两份报告，警告加密货币钱包密钥是未来量子计算攻击的主要暴露点，而区块链的哈希函数在很大程度上仍具抗量子能力。该机构敦促开发者、钱包提供商和政策制定者立即开始向抗量子密码学迁移，另一份报告则强调了"先收集、后解密"的风险，即被盗数据可能在量子计算机成熟后被破解。 这一警告表明，量子计算正从理论担忧转变为加密行业的具体规划问题，可能影响钱包、交易所和区块链协议的安全设计方式。如果行业未能做好准备，一旦量子计算机强大到能够大规模运行 Shor 算法，数十亿美元的数字资产可能面临风险。 欧洲刑警组织的网络犯罪中心发现，依赖 ECC 和 RSA 等非对称加密的钱包密钥是主要漏洞，而保护区块链的哈希函数在很大程度上仍具抗量子能力。报告还提到了"先收集、后解密"（HNDL）威胁，即攻击者今天收集加密数据，待量子能力成熟后再解密，这种情景有时被称为 Q-Day 或 Y2Q。

rss · Decrypt · Oct 7, 10:49

**背景**: 量子计算机一旦足够强大，就可以利用 Shor 算法破解保护加密货币钱包和许多其他系统的非对称加密（如 ECC 和 RSA）。与被认为对量子攻击更具抵抗力的哈希函数不同，公钥加密非常脆弱。"先收集、后解密"是一种监控策略，即今天存储加密数据，预期未来的量子计算机能够解密，这促使人们在威胁完全显现之前就呼吁向后量子密码学迁移。

## [加密行业对 Justin Drake 的 AI 密码学警告意见分裂](https://www.theblock.co/news/defi/2026-10-08-crypto-industry-split-over-justin-drakes-ai-warning-418021) ⭐️ 6.0/10
