## [Cloudflare 收购 Deno，运行时开发将终止](https://deno.com/blog/cloudflare) ⭐️ 9.0/10

Cloudflare 已收购由 Ryan Dahl 创建的 JavaScript/TypeScript 运行时 Deno，并宣布仅再支持 Deno 运行时一年，期间提供每月的错误修复和安全更新，之后将完全终止开发。Deno 将继续保持开源，但除非有其他方接手，否则该运行时在一年后将不再获得支持。 此次收购实际上终结了最著名的替代 JavaScript 运行时之一，该运行时本为解决 Node.js 的设计缺陷而创立，这标志着 JavaScript 基础设施领域权力的进一步集中。它影响了那些因 Deno 安全优先、基于 Web 标准的方法而采用它的开发者，并引发了对由风险投资支持的开源项目可持续性的担忧。 Deno 将在一年内每月发布包含错误修复和安全更新的版本，之后 Cloudflare 将停止开发该运行时；代码将继续开源，供他人继续开发。此次收购主要是为了获得 Deno 的团队，该团队构建了 Celld——Cloudflare Workers 的自托管版本，而非运行时本身。

hackernews · ilreb · Oct 9, 13:03 · [社区讨论](https://news.ycombinator.com/item?id=50019911)

**背景**: Deno 是一个基于 V8 和 Rust 构建的 JavaScript 和 TypeScript 运行时，由 Node.js 的原作者 Ryan Dahl 创建，注重安全性（默认安全权限）和 Web 标准合规性。Cloudflare Workers 是一个用于在边缘运行 JavaScript 的无服务器平台，而 Celld 是 Deno 推出的自托管替代方案。此次收购反映了 JavaScript 生态系统的更广泛趋势，即由风险投资资助的开源项目往往面临盈利或出售的压力。
