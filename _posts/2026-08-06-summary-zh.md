## [Celld：自托管的分布式持久对象运行时](https://github.com/denoland/celld) ⭐️ 8.0/10

Celld 是一个新的开源运行时，实现了分布式持久对象，将基于 SQLite 的对象复制到兼容 S3 的存储中，为 Cloudflare 的持久对象提供了一个自托管的替代方案。 这填补了一个重要空白，为持久对象提供了开源、自托管的选项，而此前这类功能仅在 Cloudflare 等专有平台上可用。它使开发者能够在不被供应商锁定的情况下构建有状态的分布式应用，可能加速持久对象模式的采用。 Celld 将每个对象的 SQLite 数据库复制到兼容 S3 的存储桶中，确保持久性和可用性。该项目托管在 GitHub 的 Deno 组织下，仓库说明中注明禁用拉取请求，期望通过 git format-patch 提交贡献。

hackernews · calvinfo · Aug 5, 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**背景**: 持久对象是一种编程模型，其中每个对象都是一个全局唯一、单线程的计算实例，具有持久存储，通过避免并发问题简化了有状态的分布式系统。Cloudflare 的持久对象使用 SQLite 进行存储，而 Celld 旨在以自托管方式复制这一概念，使用 SQLite 和兼容 S3 的存储进行复制。
