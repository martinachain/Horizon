## [苹果在 macOS 27 Golden Gate 中弃用 hdiutil](https://lapcatsoftware.com/articles/2026/8/7.html) ⭐️ 7.0/10

苹果已在 macOS 27 Golden Gate 中弃用了命令行工具 hdiutil，这标志着磁盘映像和 RAM 磁盘管理方式的转变。此弃用已在苹果的开发者文档中宣布，并引发了社区讨论。 hdiutil 是开发者和高级用户创建、挂载和转换磁盘映像以及创建 RAM 磁盘的核心工具。其弃用引发了对这些工作流未来的担忧，并反映了苹果更广泛的维护优先级，可能迫使用户迁移到 diskutil 等替代工具。 弃用意味着 hdiutil 将不再获得重大更新，尽管它可能仍保留在系统中以保持兼容性。社区成员指出，类似的弃用（如 xip）并未导致实际移除，表明 hdiutil 可能会持续存在多年。具体的替代路径尚不明确，但 diskutil image 被提及为潜在的替代方案。

hackernews · zdw · Aug 22, 19:04 · [社区讨论](https://news.ycombinator.com/item?id=49402741)

**背景**: hdiutil 是 macOS 的命令行工具，用于创建、挂载和转换磁盘映像文件（如 DMG），以及创建 RAM 磁盘。它与管理物理磁盘和卷的 diskutil 协同工作。RAM 磁盘是存储在内存中的虚拟磁盘，提供快速的临时存储。此次弃用是苹果持续演进 macOS 工具的一部分，尽管该公司历来在移除已弃用工具方面进展缓慢。
