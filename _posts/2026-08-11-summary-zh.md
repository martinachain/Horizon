## [Needle2：面向边缘设备的 14MB 智能体 LLM](https://cactuscompute.com/needle) ⭐️ 7.0/10

Cactus 发布了 Needle2，一个 14MB 的智能体 LLM，用于工具调用、设备使用和结构化提取，专为手机、可穿戴设备、智能家居设备和机器人设计。它在树莓派 5 上达到每秒 500 个 token，并在 28MB 内存中运行。 这意义重大，因为它将端侧 AI 推向超小模型，使缺乏 NPU 的低功耗设备能够运行智能助手，可能将 AI 扩展到数十亿物联网设备。它挑战了边缘 AI 需要高端硬件的观念。 Needle2 基于简单注意力网络，使用 Hadamard MLP 替代 FFN，采用 GQA 注意力和 engram 键值记忆。它有 4500 万参数，2 位压缩，可在 Mac/PC 上几分钟到几小时内完成微调。

**背景**: 边缘 AI 通常在 Mac 和 PC 等强大设备上运行，但大多数物联网设备是低功耗的。Needle2 采用简单注意力网络架构，去掉 MLP，依赖外部知识源如工具列表，使其在函数调用上高效。该模型专为工具调用和提取等结构化任务设计，而非开放式生成。

## [VectorWare 让 Rust 可移植 SIMD 在 GPU 上运行](https://www.vectorware.com/blog/simd-on-gpu/) ⭐️ 7.0/10

VectorWare 宣布 Rust 的可移植 SIMD 库（core::simd）现在可以编译并在 GPU 上运行，将 SIMD 向量直接映射到 GPU 的 warp，无需使用 intrinsics 或重写代码。这使得相同的 Rust SIMD 代码可以同时面向 CPU 和 GPU。 这一进展通过复用熟悉的 SIMD 抽象简化了 Rust 中的 GPU 编程，可能降低高性能计算的门槛。它有望带来跨 CPU 和 GPU 架构更可移植、更易维护的代码，影响科学计算和图形学等领域。 该实现将每个 std::thread 映射到 GPU 的 warp，并利用 warp 内的并行通道进行 SIMD 操作。然而，可移植 SIMD 目前仅在 nightly Rust 中可用，且固定宽度的 SIMD 向量在缺乏静态 GPU 信息时可能无法达到最佳性能。

hackernews · sagacity · Aug 10, 18:12 · [社区讨论](https://news.ycombinator.com/item?id=49247477)

**背景**: SIMD（单指令多数据）允许处理器同时对多个数据执行相同操作。Rust 的可移植 SIMD 库提供了与目标无关的 SIMD 操作抽象，不同于特定目标的 intrinsics。VectorWare 是一个将 Rust 线程带到 GPU 的项目，这一新能力将其扩展到 SIMD 操作。
