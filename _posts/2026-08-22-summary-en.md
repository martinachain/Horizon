## [Accidental Discovery: Logging Phone Queries to Military Bases via Forgotten e164.arpa](https://lina.sh/blog/hijacking-e164-arpa) ⭐️ 8.0/10

An individual accidentally discovered a live but forgotten e164.arpa infrastructure and logged hundreds of thousands of phone call routing queries, including those to military bases. This reveals that the public ENUM system, thought to be dead, still has active remnants. This highlights hidden remnants of public telephony infrastructure that can pose security and privacy risks. It underscores the need for better oversight and decommissioning of legacy systems to prevent unintended data exposure. The author did not set up a SIP server to see if queries led to actual call terminations, as suggested by a commenter. The e164.arpa domain is used for ENUM, which translates phone numbers into DNS queries for routing calls over IP networks.

hackernews · gavide · Aug 21, 13:11 · [Discussion](https://news.ycombinator.com/item?id=49387570)

**Background**: ENUM (E.164 Number Mapping) is a protocol defined by the IETF that translates telephone numbers into domain names under e164.arpa for DNS-based routing. It was designed to bridge the PSTN and IP networks, but public adoption has been limited, with many carriers using private ENUM services. The e164.arpa domain is managed by the ITU and is largely unused publicly, but remnants may still exist.

## [Coldcard Firmware Update Adds User Entropy After $130M Bitcoin Exploit](https://decrypt.co/376270/coldcard-new-security-after-bitcoin-exploit) ⭐️ 8.0/10

Coinkite released a Coldcard firmware update that requires users to add their own randomness (dice, coin flips, or keyboard mashing) when generating wallet seeds, addressing a critical entropy flaw that led to a $130 million Bitcoin exploit. The update also fixes additional security issues uncovered during a three-week review. This update is critical for hardware wallet security, as the entropy flaw could allow attackers to predict seed phrases and steal funds. It underscores the importance of user-supplied randomness in cryptographic key generation and may influence industry standards for hardware wallets. The vulnerability reduced effective entropy from roughly 128 bits to as low as 40 bits on some models due to a predictable RNG fallback and 32-bit reseed issue. Seeds generated on vulnerable devices remain insecure even if moved to other wallets, so users must regenerate seeds with the new firmware.

rss · Decrypt · Aug 21, 21:31

**Background**: Hardware wallets generate seed phrases using random number generators (RNGs) to create cryptographic keys. If the RNG is flawed, the seed becomes predictable, allowing attackers to derive private keys and steal funds. The Coldcard exploit is one of the largest hardware wallet security crises in Bitcoin's history, highlighting the need for robust entropy sources.
