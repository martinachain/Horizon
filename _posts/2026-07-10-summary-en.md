## [Running GLM 5.2 on a 32GB RAM Laptop with Colibrì](https://github.com/JustVugg/colibri) ⭐️ 7.0/10

A developer created Colibrì, a minimal C-based inference engine that runs the 744B-parameter GLM 5.2 model on a 32GB RAM laptop using int4 quantization and on-demand expert streaming from disk. This demonstrates that even extremely large Mixture-of-Experts models can be run on consumer hardware without a GPU, opening up local inference of state-of-the-art LLMs to a wider audience. The engine is a single ~1,300-line C file with no BLAS or Python runtime, achieving ~0.1 tok/s on cold start by keeping the dense part (~9.9 GB) in RAM and streaming routed experts (~370 GB) from disk with an LRU cache.

hackernews · vforno · Jul 9, 08:05 · [Discussion](https://news.ycombinator.com/item?id=48842459)

**Background**: GLM 5.2 is a 744B-parameter Mixture-of-Experts model with 40B active parameters per token, developed by Z.AI. Int4 quantization reduces memory footprint by storing weights in 4-bit integers. Multi-Token Prediction (MTP) is a technique that predicts multiple future tokens simultaneously to speed up inference.
