## [研究人员从专有 LLM API 中窃取推理痕迹](https://stolen-thoughts.com/) ⭐️ 8.0/10

一项新技术被展示，可以通过将推理痕迹重放到更弱、更容易被越狱的模型中，从专有 LLM API 中“窃取”隐藏的推理痕迹。该方法发布在名为 stolen-thoughts.com 的网站上，并在 AI 社区引起了广泛关注。 这很重要，因为它暴露了专有 LLM API 中潜在的安全和透明度缺陷，使用户能够访问提供商原本打算隐藏的推理过程。这可能影响 AI 透明度、竞争优势以及围绕模型输出使用的伦理辩论。 该技术涉及从前沿模型获取推理痕迹，并将其重放到较弱的兄弟模型中，然后通过越狱揭示痕迹。据报道，即使 API 摘要未保留答案与推导之间的区别（如 Opus 4.8 在某些 AIME 问题中的情况），该方法仍然有效。

hackernews · quantumgarbage · Aug 11, 13:22 · [社区讨论](https://news.ycombinator.com/item?id=49257876)

**背景**: 推理模型，也称为大型推理模型（LRM），是通过生成中间步骤（称为推理痕迹）来进行多步问题解决的 LLM。专有 LLM API 通常隐藏这些痕迹以保护知识产权并防止模型提取攻击，即对手通过查询 API 来构建替代模型。这项技术突显了模型提供商与寻求提取隐藏信息者之间持续的猫鼠游戏。

rss · Decrypt · Aug 10, 19:56

**背景**: 提示注入是一种攻击类型，将恶意指令嵌入 AI 模型处理的数据中，使其执行非预期操作。在此案例中，PDF 中的隐藏文本被用来操纵 Atlassian Rovo，这是一个与企业工具（如 Jira 和 Confluence）集成的 AI 助手。该漏洞由安全公司 PromptArmor 披露，并已被多家网络安全新闻媒体广泛报道。
