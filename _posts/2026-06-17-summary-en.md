## [Stop Using JWTs for Browser Sessions](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

A widely-discussed gist argues that JSON Web Tokens (JWTs) should not be used for browser-based user sessions due to security and revocation issues, while acknowledging their value in service-to-service communication. This debate impacts how developers choose authentication mechanisms for web applications, potentially shifting best practices away from JWTs for session management and toward traditional server-side sessions with cookies. The gist references concerns such as inability to revoke individual tokens, token theft via localStorage, and complexity in implementing refresh tokens. It recommends using session cookies with server-side storage for browser-based authentication.

hackernews · dzonga · Jun 16, 16:49 · [Discussion](https://news.ycombinator.com/item?id=48558147)

**Background**: JWTs are self-contained tokens that encode user claims and are signed to ensure integrity. They are commonly used for authentication in web and mobile apps, but storing them in localStorage or cookies without proper safeguards can lead to security vulnerabilities. Server-side sessions, in contrast, store session data on the server and only a session ID in a cookie, making revocation straightforward.
