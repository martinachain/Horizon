## [Kakehashi: Run macOS Binaries on Linux ARM](https://github.com/wie-project/kakehashi) ⭐️ 8.0/10

Kakehashi, an experimental userspace translation layer, now successfully runs macOS CLI binaries on Linux ARM64, with working prototypes for 7-Zip, curl, and Xcode Git tools. It translates Darwin Mach-O binaries and BSD syscalls without a JIT. This project addresses a significant technical challenge, potentially enabling macOS software to run on Linux ARM hardware, similar to Wine/Proton for Windows apps. It could expand the Linux ecosystem and offer an alternative to Darling, especially on ARM platforms. Kakehashi is CLI-first and does not use JIT; it maps a freestanding libSystem and translates BSD syscalls. Current performance shows 7-Zip running ~5.2x slower than native Linux, but an optimization plan is in place.

hackernews · vlad_kalinkin · Aug 2, 16:26 · [Discussion](https://news.ycombinator.com/item?id=49145937)

**Background**: macOS binaries use the Mach-O format and rely on macOS system libraries (e.g., libSystem) and BSD syscalls. Running them on Linux requires translating these components. Darling is a similar project that aims to provide a macOS compatibility layer on Linux, but its ARM64 support is still in progress.
