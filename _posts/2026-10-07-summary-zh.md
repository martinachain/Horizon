## [OpenAI 公布 AI 生成的重大数学猜想证明](https://openai.com/index/sharing-ai-progress-in-mathematics/) ⭐️ 10.0/10

OpenAI 在 GitHub 上发布了名为 openai/math 的仓库，其中包含由内部前沿模型生成的数学手稿和 Lean 证明形式化文件，声称证明了唯一游戏猜想（Unique Games Conjecture）和巴内特猜想（Barnette's Conjecture）。该发布还配有一个名为“Sharing AI progress in mathematics”的页面，共涵盖 722 篇针对开放研究问题的论文手稿。 如果这些结果得到验证，将代表数学研究范式的转变，因为唯一游戏猜想是理论计算机科学中许多近似困难性结果的基础，而巴内特猜想已悬而未决数十年。该消息引发了激烈讨论（767 分、695 条评论），研究人员指出教科书可能需要重写，AI 正开始回答关于人类数学理解极限的长期问题。 该仓库包含预印本和 Lean 证明形式化文件，其中巴内特猜想被列为第 180 号问题；曾用最先进模型尝试过该问题的评论者表示，这些证明乍看之下似乎平易近人。所使用的模型仅被描述为“OpenAI 内部模型”，尚未公开命名或发布。

hackernews · OfficialTurkey · Oct 6, 22:17 · [社区讨论](https://news.ycombinator.com/item?id=49984923)

**背景**: 唯一游戏猜想由 Subhash Khot 于 2002 年提出，认为近似计算某种类型游戏的值是 NP 困难的，并对许多优化问题的近似困难性具有广泛影响。巴内特猜想是图论中的一个开放问题，断言每个顶点度数为三的二部多面体图都具有哈密顿回路。Lean 是一种交互式定理证明器，可将数学证明形式化并进行机器验证，为检查 AI 生成证明的正确性提供了途径。

## [OpenAI 推出 Decisions API 公开测试版，专注二元决策](https://developers.openai.com/api/docs/guides/decisions) ⭐️ 8.0/10

OpenAI 已推出 Decisions API 的公开测试版，这是一种快速且低成本的模型，旨在返回二元或基于置信度的决策，而非生成文本。该 API 通过新的 /v1/decisions 端点访问，并使用如 gpt-6-luna 等模型，开发者 Simon Willison 已进行了演示。 这标志着一个重要的新产品类别——System One 模型——通过为简单的分类和路由任务提供比完整文本生成更便宜的替代方案，可能重塑 AI 定价和架构。同时，这也加剧了关于 AI 商品化的争论，因为大公司为了留住客户而竞相降价。 该 API 返回带有校准概率和置信度值的类型化答案，使其适用于分类和路由等重复性小决策。社区成员已将其与 Jev 和 Mercury Decide 等替代方案进行了测试，指出其可负担性以及替代更昂贵模型调用的潜力。

hackernews · chiefstorm · Oct 6, 20:57 · [社区讨论](https://news.ycombinator.com/item?id=49984025)

**背景**: System One 模型是一种 AI 决策模型，它返回类型化答案和校准概率，而不是生成的文本，专为软件内部的自动化决策而设计。它们与生成文本的传统大型语言模型形成对比，为二元或基于置信度的任务提供更快、更便宜的推理。Decisions API 顺应了 AI 商品化的更广泛趋势，即模型变得越来越易获取和可负担。

## [Mistral 发布 Large 4，在欧洲用 3800 块 Blackwell GPU 训练](https://mistral.ai/news/mistral-large-4//) ⭐️ 8.0/10

Mistral AI 发布了 Mistral Large 4，这是一款全新的旗舰级开放权重多模态大模型，在其位于欧洲的自有数据中心使用 3800 块 NVIDIA Grace Blackwell GPU 从零开始训练。该模型采用细粒度混合专家（MoE）架构，总参数 1.05T、激活参数 52B，并配备 1.6B 视觉编码器，在视觉和网络安全基准测试中表现强劲。 这是欧洲 AI 主权的重要里程碑，表明前沿级别的模型可以完全在欧盟境内、仅用约 4000 块 GPU 完成训练，有望减少对美国和中国的 AI 供应商的依赖。其在网络安全方面的强劲表现，使其成为安全敏感场景中颇具吸引力的“防御型模型”。 Mistral Large 4 提供 512K token 的上下文窗口，最多可输出 256K token，并支持工具调用和结构化输出。社区测试指出，其推理设置仅提供“none”或“high”两种模式，实际差异不大，部分用户还报告在重度研究任务中工具调用存在问题。

## [谷歌发布开源多模态嵌入模型 EmbeddingGemma 2](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) ⭐️ 8.0/10

谷歌 DeepMind 发布了 EmbeddingGemma 2，这是一个采用 Apache 2.0 许可证的开放权重多模态嵌入模型，能够将文本、图像、视频帧和音频原生映射到同一个统一的向量空间中。它是参数量低于 10 亿的最强多模态嵌入模型之一，其纯文本版本在 Pixel 11 Pro 上仅占用约 191MB 内存即可运行。 这为开发者提供了一个开放且可商用的多模态检索方案，能够在设备本地运行，而无需依赖云端嵌入 API。在 LLM 和智能体工作流越来越依赖嵌入的当下，它填补了缺乏优质中等规模开源嵌入模型的空白。 该模型文本加视觉共 440M 参数，纯文本为 270M；与以往端侧嵌入模型不同，它采用 MRL 而非 MatFormers 训练，因此无法在降低嵌入维度的同时缩小模型权重。在端侧部署方面，开发者可以使用 Google AI Edge 的 MediaPipe 和 LiteRT，其中 Semantic Retriever 任务能在个位数毫秒内完成近似最近邻搜索。

hackernews · ilreb · Oct 6, 16:03 · [社区讨论](https://news.ycombinator.com/item?id=49980487)

**背景**: 嵌入模型将文本、图像等内容转换为数值向量，使相似内容在向量空间中彼此靠近，从而支撑搜索、推荐和检索增强生成等应用。多模态嵌入把这一能力扩展到多种内容类型并共享同一空间，而端侧 AI 指的是在手机或边缘硬件上本地运行这类模型，而不是把数据发送到云端。Apache 2.0 是一种宽松的开源许可证，允许商业使用和修改。

Polymarket 已推出 Protocol V2，从原有的基于 Gnosis 的架构迁移到单一的 ERC-1155 头寸合约，并使用 pUSD（Polymarket USD）作为抵押品代币。此次升级将此前多合约的结构整合为一个统一的头寸合约。 对于最大的预测市场平台之一而言，这是一次重要的架构升级，简化了其链上基础设施，并可能降低交易者的 gas 成本和操作复杂度。这也反映出 DeFi 协议正朝着更高效、更统一的智能合约设计方向发展的趋势。 ERC-1155 是一种多代币标准，允许在单一合约下同时管理同质化和非同质化代币，非常适合预测市场的各类结果代币。pUSD 是 Polymarket 在 Polygon 上的平台专属抵押品代币，专为内部使用而设计，目前没有计划在外部交易所上线。

rss · The Block · Oct 6, 14:35

**背景**: Polymarket 此前依赖 Gnosis 条件代币框架（CTF），这是一组以太坊智能合约，将事件结果表示为链上代币，以便在预言机最终确认结果后进行交易和赎回。在该系统下，每笔交易都会触及名为 ConditionalTokens.sol 的合约，该合约发行 ERC-1155 结果代币。Protocol V2 用单一的 ERC-1155 头寸合约和 pUSD 抵押品取代了这一旧有架构，使系统更加精简。
