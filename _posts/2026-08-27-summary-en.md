## [Tailcat: netcat over Tailscale's data plane for secure p2p connections](https://github.com/tailscale/tailcat) ⭐️ 8.0/10

Tailcat is a new tool that brings netcat-like functionality to Tailscale's data plane, enabling secure peer-to-peer connections without requiring public IPs. It leverages Tailscale's existing infrastructure to work seamlessly behind NAT or CGNAT. This tool simplifies secure remote access and file transfer for developers and sysadmins, especially in environments with restrictive networking. It highlights the growing trend of using overlay networks like Tailscale to bypass traditional NAT and CGNAT limitations, potentially reducing reliance on public IPs and complex port forwarding. Tailcat is designed to be a drop-in replacement for netcat, supporting similar commands and workflows. It uses Tailscale's data plane, which is built on WireGuard, to encrypt and route traffic directly between peers, ensuring low latency and high security.

hackernews · nderjung · Aug 26, 17:42 · [Discussion](https://news.ycombinator.com/item?id=49452990)

**Background**: Netcat is a classic networking utility for reading and writing data across TCP/UDP connections, often used for debugging and scripting. Tailscale is a mesh VPN that creates a secure overlay network using WireGuard, allowing devices to communicate as if on a private network, even across NAT and CGNAT. CGNAT is a technology ISPs use to share limited IPv4 addresses among many users, which often blocks inbound connections to home servers.
