## [Celld: Self-hosted, distributed durable objects runtime](https://github.com/denoland/celld) ⭐️ 8.0/10

Celld is a new open-source runtime that implements distributed durable objects, replicating SQLite-backed objects to S3-compatible storage, providing a self-hosted alternative to Cloudflare's Durable Objects. This addresses a significant gap by offering an open-source, self-hosted option for durable objects, which were previously only available on proprietary platforms like Cloudflare. It empowers developers to build stateful distributed applications without vendor lock-in, potentially accelerating adoption of the durable object pattern. Celld replicates each object's SQLite database to an S3-compatible bucket, ensuring durability and availability. The project is hosted on GitHub under the Deno organization, and the repository notes that pull requests are disabled, with contributions expected via git format-patch.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**Background**: Durable objects are a programming model where each object is a globally unique, single-threaded compute instance with persistent storage, simplifying stateful distributed systems by avoiding concurrency issues. Cloudflare's Durable Objects use SQLite for storage, and Celld aims to replicate this concept in a self-hosted manner, using SQLite and S3-compatible storage for replication.
