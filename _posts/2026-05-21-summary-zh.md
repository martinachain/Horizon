## [Mozilla 宣布弃用 asm.js，WebAssembly 的前身](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 宣布弃用 asm.js，这是一种严格的 JavaScript 子集，曾使 Web 应用实现接近原生的性能，标志着其开发和支持的终结。 asm.js 是为 WebAssembly 铺平道路的基础技术，其弃用标志着全面转向 WebAssembly 作为高性能 Web 代码的标准。 asm.js 最初在 Firefox 22 中引入，允许通过 Emscripten 在浏览器中运行 C/C++ 代码。取代 asm.js 的 WebAssembly 于 2019 年成为 W3C 推荐标准，现已得到所有主流浏览器的支持。

hackernews · eqrion · May 20, 12:01 · [社区讨论](https://news.ycombinator.com/item?id=48206340)

**背景**: asm.js 是 JavaScript 的一个严格子集，设计为 C 和 C++ 等语言的编译目标，通过限制语言特性以利于提前优化，从而实现接近原生的性能。它是 WebAssembly 的前身，后者提供了更高效的二进制格式，现已成为高性能 Web 应用的标准。
