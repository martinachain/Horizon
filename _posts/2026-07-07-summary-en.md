## [Ternlight: 7MB Embedding Model Runs in Browser via WASM](https://ternlight-demo.vercel.app/) ⭐️ 8.0/10

Ternlight is a 7MB sentence embedding model distilled from MiniLM using ternary quantization, with a custom inference engine written in Rust and compiled to WebAssembly with SIMD, enabling efficient local semantic search entirely in the browser. This demonstrates that high-quality embedding models can run entirely client-side, preserving user privacy and enabling offline semantic search without server costs, which is significant for privacy-sensitive applications and resource-constrained environments. The model outputs 384-dimensional embeddings and uses cosine similarity for semantic comparison. Ternary quantization reduces model size by 16x compared to full-precision, while WASM SIMD accelerates inference 2-4x over scalar WebAssembly.

hackernews · soycaporal · Jul 6, 23:06 · [Discussion](https://news.ycombinator.com/item?id=48811644)

**Background**: Sentence embedding models convert text into numerical vectors that capture semantic meaning, enabling tasks like semantic search and clustering. MiniLM is a popular efficient sentence embedding model, and ternary quantization represents weights as {-1, 0, +1} to reduce size while maintaining accuracy. WebAssembly with SIMD allows near-native performance in browsers by executing compiled code with single-instruction multiple-data parallelism.

## [Vitalik Buterin Proposes 'Extremely Lean' Ethereum with Near-Zero State via ZK Proofs](https://www.theblock.co/post/407319/vitalik-buterin-extremely-lean-ethereum-shrinking-chain-to-near-zero-state-zk-proofs?utm_source=rss&utm_medium=rss) ⭐️ 8.0/10

Ethereum co-founder Vitalik Buterin proposed a two-step plan to shrink Ethereum's state to near-zero using zero-knowledge (ZK) proofs, shifting state management from the chain to validators and replacing per-epoch balance updates with ZK proofs. This proposal could drastically reduce Ethereum's state size, improving scalability and efficiency, and lowering storage requirements for nodes, which is critical for the network's long-term decentralization and growth. The plan involves two steps: first, shifting state management to validators, and second, replacing per-epoch balance updates with ZK proofs, effectively making the chain's state nearly empty. This approach builds on Ethereum's roadmap toward statelessness and state expiry.

rss · The Block · Jul 6, 16:34

**Background**: Ethereum's state is the current snapshot of all accounts and contract data, stored in a Merkle Patricia Trie. As the network grows, the state becomes larger, increasing storage and computational costs for nodes. Zero-knowledge proofs allow one party to prove a statement's validity without revealing the underlying data, and they are already used in ZK-rollups for scalability. Buterin's proposal aims to apply ZK proofs to state management itself, potentially eliminating the need for full state storage on-chain.
